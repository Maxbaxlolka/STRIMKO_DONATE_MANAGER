STRIMKO DONATE MANAGER
=======================

Готовая панель управления виртуальными донатами для GitHub Pages и OBS.

ВАЖНО
-----
В оверлее есть маленькая пометка DEMO. Она показывает, что уведомление тестовое.

КАК ЗАГРУЗИТЬ НА GITHUB
-----------------------
1. Создай новый публичный репозиторий, например STRIMKO-DONATE.
2. Загрузи ВЕСЬ СОДЕРЖИМЫЙ архива в корень репозитория.
3. Открой Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main.
6. Folder: / (root).
7. Нажми Save.
8. Подожди 1-3 минуты.

ССЫЛКИ
------
Оверлей для OBS:
https://ТВОЙ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/

Панель управления:
https://ТВОЙ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ/control.html

КАК ДОБАВИТЬ В OBS
------------------
1. Нажми плюс в списке источников.
2. Выбери "Браузер".
3. Вставь ссылку на index.html.
4. Ширина: 1920.
5. Высота: 1080.
6. Поставь источник выше захвата игры.

КУДА ДОБАВЛЯТЬ ЗВУКИ
---------------------
Папка:
sounds

Пример:
sounds/bruh.mp3
sounds/vine-boom.mp3
sounds/wow.mp3

После загрузки звуков открой script.js.
Найди раздел:
СЮДА ДОБАВЛЯЙ ЗВУКИ

И впиши:
const SOUNDS = [
  "sounds/bruh.mp3",
  "sounds/vine-boom.mp3",
  "sounds/wow.mp3"
];

Лучше использовать звуки короче 15 секунд.
Поддерживаются mp3, wav и ogg.

КУДА ДОБАВЛЯТЬ GIF
------------------
Папка:
gifs

Пример:
gifs/cat.gif
gifs/dance.gif
gifs/meme.gif

После загрузки GIF открой script.js.
Найди раздел:
СЮДА ДОБАВЛЯЙ GIF

И впиши:
const GIFS = [
  "gifs/cat.gif",
  "gifs/dance.gif",
  "gifs/meme.gif"
];

КУДА ДОБАВЛЯТЬ АВАТАРКИ
------------------------
Папка avatars уже создана на будущее.
В текущей версии без GIF показываются цветные аватарки с буквами ника.

ГДЕ ДОБАВЛЯТЬ НИКИ
-------------------
Открой script.js.
Найди:
СЮДА ДОБАВЛЯЙ НИКИ

Добавляй новые ники в массив NAMES.

ГДЕ ДОБАВЛЯТЬ СООБЩЕНИЯ
------------------------
Открой script.js.
Найди:
СЮДА ДОБАВЛЯЙ СООБЩЕНИЯ

Добавляй сообщения в массив MESSAGES.
